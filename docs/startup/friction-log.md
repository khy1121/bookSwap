### 원문 형태 예시
- "경영 회계책(현대투자론/조직이론/경영전략/공급사슬/하이테크) 팝니다" — 5권 묶음, 제목으로 개별 검색 불가
- "컴공 전공책 판매합니다. 2권 이상 구매할시 네고" — 책 제목 없음, 본문 열어야 앎
- "C언어 자료구조 / 빅데이터 세상 / 명품 java 프로그래밍 / 데이터베이스 이해 책 팝니다"

### G0에 주는 의미
1. **수요는 확실히 존재**: 장터 글의 72%가 교재. 교재 거래가 이 게시판의 주 용도다.
2. **경쟁자가 놓친 지점 확인**: 과목·교수 기준 구조가 없어서 (a) 묶음 판매 글은 검색 불가, (b) 학과 단위로 뭉뚱그림, (c) 판본 정보가 본문 자유 텍스트에 흩어짐.
3. **판매자 쪽 아픔 = 재게시**: 3주 뒤 같은 글을 다시 올리는 사람이 있다 → 매칭 실패가 실제로 발생.
4. **⚠ 매수 글 0건의 두 가지 해석**
   - 낙관: 매수자는 글을 안 쓰고 검색·쪽지만 한다 → 매수 수요가 게시판에서 **보이지 않을 뿐**
   - 비관: 매수 수요 자체가 약하다 (새 책·PDF·학교 앞 서점으로 충분)
   - **L0 시트에서 "삼" 행이 쌓이는지가 이 해석을 가른다.** 이것이 L0의 가장 중요한 관측 항목.
