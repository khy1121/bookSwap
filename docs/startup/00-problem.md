# G0. 문제 진술 — 과목 기준 교재 거래 (가칭: 북스왑@한성)

## 문제
- **누가:** 한성대 같은 학과 학생. 특히 (a) 수강신청 직후 교재를 구하는 학생, (b) 종강 후 교재를 처분하려는 학생
- **언제:** 학기 시작 1~2주(3월/9월) 매수 폭주, 종강 직후(6월/12월) 매도 폭주. 나머지 기간은 거의 없음 → 계절성 강함
- **지금 어떻게 때우고 있는가:** 에브리타임 장터 게시판 + 쪽지, 학과 단톡, 당근마켓 검색("OO개론"), 학교 앞 중고서점
- **그게 왜 아픈가:**
  - 시간: 게시판은 강의/교수 기준 검색이 안 됨. 제목을 붙이는 방식이 제각각("데구", "데이터베이스 개론 3판")이라 검색 실패
  - 돈: 새 책 3~4만 원 vs 중고 1~1.5만 원. 못 구하면 새 책 구매
  - 실수: 판본 불일치(2판/3판), 교수 변경으로 교재 바뀜 → 헛구매
- **내가 직접 겪었는가:** **예.** 에브리타임 장터로 직접 교재를 사고팔았음 (게시판 검색 실패·제목 표기 제각각·쪽지 왕복을 직접 경험)

## 현장 증거 (2026-08-27 에타 장터 40건 관측 — friction-log.md)
- 장터 글 72%가 교재. 교재 매물은 29건, **매수 글 0건**
- 제목이 "컴공 전공책", "경영 회계책(5권 묶음)" 식이라 과목 기준 검색 불가. 교수명 언급 1/29
- 같은 책을 3주 뒤 재게시한 사례 3건 → 매칭 실패 실재

## 경쟁 서비스가 놓친 지점 (한 문장)
당근·번개장터·에브리타임 모두 **"어떤 강의(교수·학기)에서 쓰는 책인가"** 를 기준으로 매수/매도를 매칭하지 못한다.

## 좁고 깊은 우물
- 초기 타겟: **한성대 1개 학과(본인 학과) 1개 학기.** 다른 학교·학과는 코드에 넣지 않음 (`school_id`, `tenant_id` 없음)
- 초기 카탈로그: 해당 학과 이번 학기 개설 과목 + 지정 교재 목록을 **내가 수동으로** 채움
