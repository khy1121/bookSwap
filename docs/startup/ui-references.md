# UI/UX 레퍼런스 (wwit.design, 2026-08-27)

우리 화면 4개(검색 홈 / 과목 상세 / 매물 상세 / 등록)에 대응되는 패턴만 추림. 당근·번개장터는 wwit에 없음.

| 우리 화면 | 레퍼런스 | 가져올 패턴 | 링크 |
|---|---|---|---|
| 과목 상세 | **KREAM 상품 상세** | 상단 상품(=교재) 정보 고정 + 하단 **구매/판매 이중 CTA**에 각각 "즉시 가격" 표기. 우리: "팔아요 n건 · 최저 12,000원 / 구해요 n건 · 최고 15,000원" | wwit.design/2021/04/29/kream/ |
| 판본 선택 | **KREAM 사이즈 선택 시트** | 그리드 칩 + 칩 아래 현재가. 우리: 판본(4판/5판/개정5판) 칩 + 매물 수 | 동일 |
| 등록 | **KREAM 보유 상품 추가** | 상품은 이미 확정된 상태로 상단에 카드로 고정, 사용자는 사이즈·가격만 입력. 우리: 과목·교재는 고정 카드, 입력은 판본·가격·연락처 3개 | 동일 |
| 등록(대안) | **헤이딜러 내차팔기** | 한 화면에 질문 하나(번호판 → 소유자명 → 확인). "번호판 하나로 시작" = "과목 하나로 시작". 폼이 아니라 대화형 진행 + 하단 파란 안내 말풍선 | wwit.design/2023/04/04/heydealer/ |
| 매물 상세 | **헤이딜러 차량 정보** | 라벨-값 2열 표 + 공식 데이터(차량 이력)와 사용자 입력을 구분 표시. 우리: "교수 지정 교재"(공식) vs "판매자 입력"(사용자) 구분 | 동일 |
| 검색 홈 | **KREAM 홈 검색** | 홈 상단 검색바 + 최근 항목. 우리: 이미 구현. 추가로 "내 수강 과목" 칩 저장(localStorage) 고려 | 동일 |

## 적용 우선순위 (L0 결과 나오기 전엔 구현 안 함)
1. 과목 상세 하단 고정 CTA 2개 + 최저/최고가 — 현재 버튼 2개는 있으나 가격 정보 없음
2. 등록 화면을 "고정 카드 + 3개 입력"으로 축소 — 현재 8개 필드
3. 판본 칩 — 카탈로그에 판본 정보 있는 과목(164건)부터

## 안 가져올 것
- 29CM / 오늘의집 스타일 에디토리얼·이미지 중심 홈 — 교재는 이미지가 의미 없음
- KREAM 온보딩(회원가입 4단계) — 우리는 매직링크 1단계


## 적용 기록 (2026-08-27, 사용자 결정으로 L0 전 적용)
- 용어: 팔아요/구해요 → **판매 / 구매**, 사람은 **판매자 / 구매자** (`lib/types.ts` KIND_LABEL·ROLE_LABEL)
- 레이아웃: KREAM식 — 모바일 폭(max-w-md), 상단 상품(교재) 카드 고정, 과목 상세 하단 고정 이중 CTA(구매=최저 판매가 / 판매=최고 구매가), 매물 상세 하단 고정 "○○에게 연락하기"
- 색상: 한성대 홈페이지 CSS 추출 — 블루 #0a4da1(구매), 스카이 #0599d9(판매), 네이비 #002c77, 액션 #0064ef, 그레이 #333/#666/#767676, 라인 #ececec, 소프트 #f3f7ff
- 서체: Pretendard Variable (한성대 홈페이지 동일), 과목 코드 라벨만 mono
- 시그니처: 수강편람 시간표 셀을 닮은 `.course-code` 라벨 (왼쪽 블루 바 + 소프트 블루 배경)
- 등록 폼: 구매/판매 토글 → 교재명·판본·가격·연락처 (+판매 시 상태). 구매일 땐 상태 필드 숨김
